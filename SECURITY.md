# Security Policy

## Reporting a Vulnerability

請勿在 GitHub Issues 公開回報保安漏洞。

請透過 **GitHub Security Advisory**（Repository → Security → Report a vulnerability）私下回報，我們會在 **48 小時內**確認收到，並於修復後一併發佈。

Please do not open a public GitHub issue for security vulnerabilities. Report privately via the **GitHub Security Advisory** flow; we acknowledge reports within **48 hours**.
